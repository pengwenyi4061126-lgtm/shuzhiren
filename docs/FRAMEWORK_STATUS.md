| 模块 | 当前状态 | 4090 到位后如何接入 |

| 控制面命令 | 直播场次可创建并排期，自动冻结商品版本、渠道、运行时会话及含备用/人工段落的节目修订；状态迁移、幂等命令与媒体 outbox 均具备开发内存/PostgreSQL Repository 双模式 | 在 PostgreSQL 上做并发、断网和重试集成测试；后续接 Redis 队列 |
| 商品事实与预检 | 商品、版本创建、审批、批准版本查询、节目段落和预检硬校验均具备开发内存/PostgreSQL Repository 双模式；受控回复草稿仅引用已批准版本事实并附带证据版本 | 接 ERP/PIM、审核后台，并在 PostgreSQL 上做并发版本创建测试 |
| 策略引擎 | 互动问题可租户隔离持久化，基于规则与证据判定回答或转人工；场控处理与审计留痕已建立，并提供独立的策略核验工作区给运营和审核角色。已批准商品事实可生成受控语音草稿，场控确认后写入可重试、幂等的语音 outbox；CI 会运行提示注入、密钥索取、诱导改价、医疗承诺和特殊人群等红队集 | 增加可版本化策略包和基于真实语料的扩展评测集 |
| 渠道适配 | 渠道连接、服务端 Adapter 能力注册表、受管密钥引用、验证证据与 24 小时预检校验已建立；标准化评论入口仅接受私网 Adapter，以每租户独立 token 约束身份、校验场次/渠道绑定并按外部事件幂等入队 | 每个平台实现独立 Adapter、OAuth/Webhook 与商品同步 |

| 数据库 | 完整迁移、RLS、OIDC 操作者同步、直播场次、商品事实、节目单、素材授权、渠道连接、运行遥测、告警与 append-only 审计 Repository 已建立 | 租机后启动 PostgreSQL、执行迁移并做并发、故障恢复和权限隔离集成测试 |
| 基础设施 | Compose、CI、运行遥测上报接口、私网 runtime-observer、告警自动开闭、审计证据、场次时间线与监控页已建立；observer 只有同时得到 Gateway 会话/GPU事实与外部输出探针事实后才上报，缺失时默认 fail-closed。worker 还会对超过 60 秒未更新的 LIVE 遥测原子降级、写审计并进入备用/人工 outbox，恢复必须人工确认。PostgreSQL 归档备份与结构校验脚本只允许创建/验证，不允许自动覆盖恢复；CI 会在临时 PostgreSQL 上执行全部迁移与架构验证 | 部署到 Linux 服务器，完成已验收的平台目的端探针、站外对象复制、隔离恢复演练，注入运行时服务令牌并接入通知通道 |
