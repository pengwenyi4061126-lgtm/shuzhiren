# 框架状态

当前代码仓库已经具备不依赖 GPU 的产品框架：

| 模块 | 当前状态 | 4090 到位后如何接入 |
| --- | --- | --- |
| Web 控制台 | 可运行，生产 API 强制 OIDC JWT 并从 claims 解析租户和角色；指挥台已接入场次、遥测、告警与服务端命令，场次页可聚合命令、媒体投递、告警、互动和审计时间线 | 配置真实 OIDC 提供商、SSO 和成员同步 |
| 控制面命令 | 直播场次可创建并排期，自动冻结商品版本、渠道、运行时会话及含备用/人工段落的节目修订；状态迁移、幂等命令与媒体 outbox 均具备开发内存/PostgreSQL Repository 双模式。CI 临时 PostgreSQL 会验证 `RECOVER` 保持降级直至 Gateway 确认、重复确认被拒绝，以及遥测超时后的告警/审计/备用投递 | 在真实 4090 上做网络中断、Gateway 重启和多 worker 并发压测；后续接 Redis 队列 |
| 商品事实与预检 | 商品、版本创建、审批、批准版本查询、节目段落和预检硬校验均具备开发内存/PostgreSQL Repository 双模式；价格/库存事实必须带来源凭据、同步时间和有效期，来源超过 24 小时或不在有效期不能被批准、用于新建场次或自动播报；受控回复草稿仅引用当前已批准版本事实并附带证据版本 | 接 ERP/PIM、审核后台，并在 PostgreSQL 上做并发版本创建测试 |
| 策略引擎 | 互动问题可租户隔离持久化，基于规则与证据判定回答或转人工；场控处理与审计留痕已建立，并提供独立的策略核验工作区给运营和审核角色。已批准商品事实可生成受控语音草稿，场控确认后写入可重试、幂等的语音 outbox；CI 会运行提示注入、密钥索取、诱导改价、医疗承诺和特殊人群等红队集 | 增加可版本化策略包和基于真实语料的扩展评测集 |
| 渠道适配 | 渠道连接、服务端 Adapter 能力注册表、受管密钥引用、验证证据与 24 小时预检校验已建立；标准化评论入口仅接受私网 Adapter，以每租户独立 token 约束身份、校验场次/渠道绑定并按外部事件幂等入队。交易入口使用独立租户密钥，幂等接入无 PII 的曝光、点击、加购、支付和退款，支付/退款审计并可按场次聚合净回款、退款率和漏斗 | 每个平台实现独立 Adapter、OAuth/Webhook、商品同步与经商品成本核验的贡献毛利 |
| 媒体运行时 | Runtime Gateway、源码锁定、LiveTalking/CosyVoice 音频链路、GPU Compose 和模型/运行时发布登记已建立；外置观测补丁会导出会话、录制、进程内 FPS、RTMP writer 状态与 NVML GPU 指标，部署预检验证补丁可应用。发布包需要源码、镜像、权重哈希、授权范围、验收证据和审核，场次冻结的版本会在预检复核 | 租机后下载受许可权重，完成 4090 端到端压测、平台目的端探针与 durable outbox 投递；开发 fixture 不构成发布证据 |
| 数据库 | 完整迁移、RLS、OIDC 操作者同步、直播场次、商品事实、节目单、素材授权、渠道连接、运行遥测、告警与 append-only 审计 Repository 已建立；新审计事件还按租户写入数据库级 SHA-256 哈希链，审计页/API 可验证链头与序列一致性，迁移前历史记录明确标为未纳入链 | 租机后启动 PostgreSQL、执行迁移并做并发、故障恢复和权限隔离集成测试 |
| 基础设施 | Compose、CI、运行遥测上报接口、私网 runtime-observer、告警自动开闭、场控确认接手、事故单、审计证据、场次时间线与监控页已建立；确认不等同于恢复，系统仍依据新遥测自动关闭告警。告警可建立唯一事故单，首个场控成为责任人，关闭时必须填写处置结论并审计。`alert-notifier` 对每租户的已配置 HTTPS Webhook 创建可租约重领、HMAC 签名、指数退避的持久化告警投递；CI 以临时 PostgreSQL 验证实际投递。管理员可设置并发场次与当月直播分钟额度；worker 写入幂等分钟桶，手动/定时开播均会检查已配置额度。录制归档服务在完成对象存储复制和 SHA-256 校验后，以独立私网凭据登记不可变对象键、时长、大小与留存日期；后台只展示证据元数据，不暴露下载地址或存储凭据。observer 只有同时得到 Gateway 会话/GPU事实与外部输出探针事实后才上报，缺失时默认 fail-closed。worker 还会对超过 60 秒未更新的 LIVE 遥测原子降级、写审计并进入备用/人工 outbox，恢复必须人工确认。PostgreSQL 归档备份与结构校验脚本只允许创建/验证，不允许自动覆盖恢复；CI 会在临时 PostgreSQL 上执行全部迁移与架构验证 | 部署到 Linux 服务器，完成已验收的平台目的端探针、站外对象复制、隔离恢复演练，注入运行时服务令牌并配置通知目标 |
